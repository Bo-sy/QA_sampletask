Ссылка на тест-кейс к этому заданию
https://docs.google.com/document/d/16jWEO5wHQIBuyFKPD5yqVzwQJ1eSlVyarPQ5thQ0gSk/edit?usp=sharing

Для скачивания проекта необходимо нажать на зеленую кнопку Code(находится над файлами репозитория)->Download ZIP
Скачанный архив надо распаковать

В PyCharm необходимо открыть проект,выбрав коренной папку QA_sampletask-main(из распакованного архива выше)
В информационном окне необходимо нажать "Доверять проекту"

Перед запуском теста необходимо выполнить команду pip3 install -r requirements.txt, версия питона должна быть >= 3.12
Чтобы выполнить команду нужно открыть терминал, который находится в левой части интерфейса PyCharm

Для запуска теста через UI необходимо перейти в test->GitHub tests->test_github_qa.py и запустить тест нажатием на кнопку запуска

Для запуска через терминал необходимо выполнить команду
python -m pytest "test/GitHub tests/test_github_qa.py" -v
